## THE TEACHING LAYER (how prompting is taught)

Three modes, building toward each other:

1. **Show** — Framework images with explanations. "Here is what this is and how it works." (Framework Families page)
2. **Guide** — Step-by-step lessons. "Try this prompt. See what happens. Now try this one." (Future: guided lessons within each framework section)
3. **Play** — A playground where visitors can experiment. Paste a preset, see the output, compare frameworks. (Future: requires AI integration / backend)

The site teaches prompting by making the frameworks visible, usable, and connected. The images ARE the curriculum. Each one is a complete system. The visitor sees it, understands the metaphor, and can use it immediately.
